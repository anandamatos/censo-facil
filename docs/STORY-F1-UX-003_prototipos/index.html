Estrutura HTML Semântica e Landmarks

Elementos de região e roles ARIA identificam as áreas funcionais da página para tecnologias assistivas.

Mapa de Regiões da Página

HEADER
role="banner" Cabeçalho da instituição
<govbr-bar> · logo · identidade visual
NAV
role="navigation" aria-label="..."
Dashboard Coleta Auditoria
MAIN
role="main" id="conteudo-principal"
<section aria-labelledby="titulo-coleta">
<h2 id="titulo-coleta">Coleta de Dados</h2>
FOOTER
role="contentinfo"
© 2026 IBGE – Todos os direitos reservados
<header role="banner">

Cabeçalho da página, identificado como região de banner por leitores de tela. Deve conter logo e identidade institucional.

<nav role="navigation">

Marca a área de navegação principal. O atributo aria-label diferencia múltiplas navegações na mesma página.

<main role="main">

Indica o conteúdo principal. Deve haver exatamente um por documento. Permite skip links para usuários de teclado.

<footer role="contentinfo">

Identifica metadados e informações institucionais do rodapé da página.

  <div class="header-logo">

  </div>
</header>

<nav role="navigation" aria-label="Navegação principal">
  <!-- lista de links de navegação -->
</nav>

  <section aria-labelledby="titulo-coleta">
    <h2 id="titulo-coleta">Coleta de Dados</h2>
  </section>
</main>

<footer role="contentinfo">
  <p>© 2026 IBGE</p>
</footer>

Hierarquia de Títulos

Leitores de tela geram um índice da página baseado nos headings — saltos de nível quebram a navegação.

Hierarquia Correta

✓ Correto
H1 Censo Agropecuário 2026
H2 1. Identificação do Estabelecimento
H3 1.1 Dados do Produtor
H4 1.1.1 Informações Pessoais
H2 2. Uso da Terra
✓ Hierarquia sequencial: H1 → H2 → H3 → H4, sem saltos de nível

Hierarquia Incorreta

✗ Incorreto
H1 Censo Agropecuário 2026
H3 1. Identificação do Estabelecimento Saltou H2!
H5 1.1 Dados do Produtor Saltou H4!
✗ Saltos de nível confundem leitores de tela e impedem navegação por índice

Por que isso importa

🔖
Índice automático
Leitores de tela como NVDA e JAWS criam um índice de navegação a partir dos headings.
⌨️
Tecla de atalho H
Usuários navegam entre headings com a tecla H. Saltos quebram o fluxo de leitura.
🎯
aria-labelledby
Sections ligadas ao heading via aria-labelledby ganham contexto semântico adicional.

Labels e Associações em Formulários

A associação explícita label→input via for/id é obrigatória. Placeholder não substitui label.

Demo — Formulário Correto

✓ Correto
Informe a área total em hectares. Exemplo: 50,5
ha

Anti-padrão: Placeholder como Label

✗ Incorreto
  • ✗ O placeholder desaparece ao digitar
  • ✗ Não é vocalizado consistentemente por leitores de tela
  • ✗ Baixo contraste por padrão (falha WCAG 1.4.3)
  • ✗ Não associa o campo ao rótulo semanticamente

Atributos Essenciais (e-MAG + WCAG)

for / id Associa label ao campo; clicar no label foca o input
aria-required Indica campo obrigatório a tecnologias assistivas
aria-describedby Liga instrução adicional ao campo
aria-invalid Sinaliza estado de erro após validação

Rigor Sintático XHTML Strict

XHTML é processado como XML — erros de sintaxe causam falha fatal de parsing, não degradação graciosa.

Fechamento de tags vazias

✓ Correto
<img src="..." alt="..." />
✗ Incorreto
<img src="..." alt="...">
Aplica-se a: br, hr, input, link, meta

Atributos booleanos explícitos

✓ Correto
disabled="disabled"
✗ Incorreto
disabled
Aplica-se a: checked, readonly, selected

Case-sensitive (minúsculas)

✓ Correto
<div class="...">
✗ Incorreto
<DIV CLASS="...">
Aplica-se a: Tags e atributos

Aninhamento correto

✓ Correto
<ul><li>Item</li></ul>
✗ Incorreto
<ul><li>Item</ul></li>
Aplica-se a: Ordem inversa de fechamento

Seções CDATA para Scripts

✓ Correto 
<script type="text/javascript">
/* <![CDATA[ */
  // O parser XML trata CDATA como texto literal
  // Operadores < e && não causam erro no parser XML
  function validarPrecisao(HDOP) {
    if (HDOP < 5.0 && HDOP > 0) {
      console.log("Precisão ótima: " + HDOP);
    }
  }
/* ]]> */
</script>
< >
Operadores de comparação
→ Protegidos por CDATA
&&
Operador lógico AND
→ Não causa falha de parsing
"..."
Strings com aspas
→ Seguro dentro de CDATA

Atributos de Acessibilidade WAI-ARIA

ARIA estende a semântica HTML para componentes dinâmicos que leitores de tela não interpretam por padrão.

Demo: Captura GNSS com aria-live

📡 Captura de Coordenadas GNSS
✅ Precisão: Ótima (HDOP: 2.1)
85%
aria-live="polite" Atualizações anunciadas após interação atual terminar
aria-atomic="true" A região inteira é lida ao atualizar, não só o diff
role="progressbar" Identifica barra de progresso para tecnologias assistivas

Demo: Acordeão com aria-expanded

A captura utiliza o receptor GNSS integrado ao DMC. A qualidade é medida pelo HDOP:

  • HDOP < 5.0 Precisão ótima
  • HDOP 5.0–10.0 Precisão aceitável
  • HDOP > 10.0 Precisão insuficiente
aria-expanded true = visível, false = oculto — leitores de tela anunciam o estado
aria-controls Conecta o botão ao elemento que ele controla (pelo id)
role="region" Identifica a área do conteúdo expansível como landmark
aria-labelledby Associa a região ao botão que a controla, por id
