Seção 1

Contexto e fundamentação

A captura precisa de coordenadas geográficas é fundamental para a qualidade dos dados censitários. O Manual do Recenseador estabelece que a localização correta dos estabelecimentos é essencial para evitar omissões e sobreposições durante a cobertura do setor censitário.

Em áreas rurais, onde as unidades são mais dispersas e as referências de endereço são menos estruturadas, o georreferenciamento confiável torna-se ainda mais crítico. O componente bloqueia o encerramento do questionário quando a precisão do sinal é insuficiente, garantindo a integridade da base cartográfica do Censo Agropecuário.

Seção 2

Propriedades e atributos

Atributos observados garantem que a interface reflita instantaneamente as mudanças na qualidade do sinal captado pelo DMC.

AtributoTipoPadrãoDescrição
hdopNumbernullDiluição de precisão horizontal do sensor — quanto menor, melhor a precisão.
latNumber0.0Coordenada de latitude capturada em tempo real.
longNumber0.0Coordenada de longitude capturada em tempo real.
statusString'loading'Estado operacional: optimal, acceptable, insufficient ou error.
precisionNumber10.0Incerteza calculada (σₕ = HDOP × σ₀) em metros, conforme o Manual do Recenseador.

Segundo a especificação do WHATWG, o construtor do elemento customizado configura o estado inicial e os ouvintes de eventos; o trabalho de busca de recursos ou renderização é adiado para o connectedCallback, que pode ser chamado mais de uma vez.

Seção 3

Estados operacionais e regras de campo

Limiares de precisão que condicionam o registro automatizado durante a coleta.

HDOP ≤ 2.5m

🟢 Ótimo

"Precisão ótima para registro"

permite continuidade da coleta
2.5m < HDOP ≤ 5.0m

🟡 Aceitável

"Precisão aceitável"

orienta busca de local mais aberto
HDOP > 5.0m

🔴 Insuficiente

"Sinal bloqueado"

bloqueia encerramento do questionário

A exigência de HDOP inferior a 5.0 metros está alinhada com as práticas estabelecidas para o georreferenciamento em operações censitárias, essencial para a integridade da base cartográfica.

Seção 5

Especificação de slots

Permite a personalização de elementos internos mantendo o encapsulamento do Shadow DOM.

SlotDescrição
iconSubstitui o ícone padrão de satélite
status-messagePermite injetar orientações contextuais ou traduções em Linguagem Simples, conforme o Manual do Recenseador
actionsEspaço para botões de suporte, como o atalho para o Manual do Recenseador

A documentação de slots é suportada pelo Custom Elements Manifest através da tag JSDoc @slot. Para slots sem nome, utiliza-se @slot -.

Seção 6

Acessibilidade e comportamento

e-MAG 3.1 e WCAG 2.2 AA — para que agentes e produtores operem o sistema sem barreiras.

  • ✓Regiões vivas — o container de status usa aria-live="polite" para anunciar mudanças de precisão sem interromper o preenchimento.
  • ✓Independência de cor — todos os estados coloridos têm ícones distintos e rótulos textuais explícitos (ex: "Sinal Bloqueado"), conforme WCAG 1.4.1.
  • ✓Foco não obscurecido — indicador de foco com contraste mínimo de 3:1, nunca oculto por componentes fixos como a Barra Gov.Br (WCAG 2.4.11).

Seção 7

Custom Elements Manifest (CEM)

Formato padronizado de documentação, permitindo que ferramentas e IDEs reconheçam o componente automaticamente.

{
  "schemaVersion": "1.0.0",
  "modules": [
    {
      "kind": "javascript-module",
      "path": "src/br-gnss-tracker.js",
      "declarations": [
        {
          "kind": "class",
          "name": "BrGnssTracker",
          "tagName": "br-gnss-tracker",
          // attributes, events e slots documentados via JSDoc
        }
      ]
    }
  ]
}

O manifesto é referenciado no package.json via "customElements": "./custom-elements.json", e pode ser gerado automaticamente pela ferramenta @custom-elements-manifest/analyzer.

Seção 8

Segurança e privacidade (LGPD)

Todas as coordenadas capturadas são serializadas e encriptadas antes da sincronização.

Repouso

AES-256

Via Web Crypto API, protegendo dados locais no IndexedDB.

Derivação

PBKDF2 + salt

Prevenção contra ataques de força bruta.

Trânsito

TLS 1.3

Criptografia em canais de comunicação.

Descarte

Remoção imediata

Após sincronização — direito ao esquecimento (Art. 18 LGPD).
