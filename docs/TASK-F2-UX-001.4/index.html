Seção 1

Contexto e fundamentação

O CEM define um esquema JSON para descrever módulos JavaScript e suas declarações exportadas — classes, funções, variáveis e tipos personalizados — sendo consumido por ferramentas que geram documentação, fornecem autocompletar em IDEs e realizam verificações estáticas.

A documentação segue as diretrizes de acessibilidade WCAG 2.2 e e-MAG 3.1, garantindo que as propriedades reflitam o comportamento inclusivo do sistema. O componente atua como trava de qualidade geodésica, bloqueando o encerramento do questionário quando o sinal é insuficiente (HDOP > 5.0m).

Seção 4

Mapeamento de metadados e acessibilidade

WCAG 2.2 e e-MAG 3.1, garantindo que as propriedades reflitam o comportamento inclusivo do sistema.

  • ✓Regiões vivas (ARIA) — o componente gerencia internamente aria-live="polite" no slot de mensagens de status, sem interromper o preenchimento (e-MAG 3.1 · Comportamento).
  • ✓Target size — botões internos de recalibragem mantêm alvos de toque de no mínimo 48×48px CSS, superando o critério 2.5.8 da WCAG 2.2.
  • ✓Identidade visual — os tokens de cores em cssProperties usam a paleta institucional do IBGE (verde funcional, amarelo de alerta).

Seção 5

Validação e manutenção

Validação via CEM Analyzer

O arquivo deve ser validado garantindo que não existam inconsistências de tipos ou nomes de atributos.

npm install -D @custom-elements-manifest/analyzer
npx cem analyze --globs "src/**/*.js"

Integração com IDEs

Desenvolvedores da Fase 3 poderão utilizar este manifesto em editores como VS Code para obter autocompletar e validação imediata de tipos — por exemplo, garantindo que hdop seja sempre numérico.

Seção 6

Exemplo de uso

HTML

<br-gnss-tracker
  hdop="2.1"
  status="optimal"
  style="--color-gnss-success: #4CAF50;"
>
  <span slot="status-message">Precisão ótima para registro</span>
  <button slot="actions">📖 Manual do Recenseador</button>
</br-gnss-tracker>

JavaScript

const tracker = document.querySelector('br-gnss-tracker');

tracker.addEventListener('br-position-update', (e) => {
  console.log('Nova posição:', e.detail);
});

tracker.addEventListener('br-status-change', (e) => {
  console.log('Status alterado:', e.detail);
});
